# The Prep Ritual & The Wrap-Up

*Two fixed procedures. Same steps every time — the point is to never re-derive the process. Copy the checkboxes into your notes or just work down the page. Entry point: [[GM-HOME]]. Co-author version: `/prep-session` in Claude Code.*

---

## Part 1 — The 45-Minute Prep *(any night before the session)*

**Timebox each step. When the timer says move, move — a finished B- prep beats an unfinished A+.**

### ⏱ 0–10 · Re-enter *(read, don't write)*

- [ ] [[STATUS]] → **Where We Are** + **What's Next**.
- [ ] Latest recap → the board state section.
- [ ] [[world-in-motion]] → the **Front Tracker** table only.
- [ ] Write **three bullets**, from memory, no file-checking: *what does each player want right now?* (If you can't answer for someone, that's your spotlight gap.)

### ⏱ 10–20 · Choose *(decide, don't build)*

- [ ] **Strong start:** pick one — mid-action, a tell from a front, or an arc beat landing uninvited. Never "you wake up and…".
- [ ] **Two spotlights:** whose night is it? Rotate — check the last two recaps for who got the last ones. Pull their `players/<name>-arc.md` and pick the next due beat from its ledger.
- [ ] **One or two fronts** to show *with a face* (a person, not a status update). Usually the ones the party brushed but didn't resolve.
- [ ] ⏰ **Scan the trigger board — [[GM-HOME]] §Fire It When.** One column of "if this is true, this is due." **Do not skip this step and do not do it from memory** — it exists because built material goes stale sitting in a folder nobody opens. If a row is true, that scene is on deck. If none are, nothing is overdue.
- [ ] **Set pieces on deck:** anything the board flagged, plus whatever the party pointed at. List them; don't re-read them yet.
- [ ] Check [[the-celebration-clue-map]] critical path — is a mystery beat due, or resting?

### ⏱ 20–40 · Assemble *(build the run sheet)*

- [ ] Copy the skeleton of the last `session-NN-run-sheet` → new file. Fill: order, timing, cut lines.
- [ ] **Secrets ×10:** start with last session's unfired ones (they're banked in the old run sheet / wrap-up notes), top up to ten. Each fires **twice — shown once, said once** — and the best mouth is another PC.
- [ ] Wire each spotlight to its rolls: **3–4 real rolls with Hope/Fear stakes** per big scene, difficulties from the house ladder (11 / 13–14 / 15).
- [ ] One coin beat max ([[coin-in-sallowreach]]). One knife per PC max ([[twist-the-knife]]) — pick them now, in cold blood, not at the table.
- [ ] List **handouts and props** to print / find. (Props beat abstractions — cords, letters, papers.)

### ⏱ 40–45 · Pack

- [ ] Print list done · dice · the run sheet is Tab 1 · [[panic-button]] within reach.
- [ ] Read your strong start **out loud once**. If it sounds like a page, cut it until it's a mouth.
- [ ] *(Optional)* `tools/Build-Packet.ps1 sessions/session-NN-run-sheet.md` → one file for the tablet.

### 🔥 Only have 15 minutes?

Do **0–10 Re-enter**, then: pick a strong start, pick ONE spotlight, grab last session's unfired secrets as-is. Run everything else from [[GM-HOME]]'s routing table and [[improv-ammo]]. The repo is deep enough to carry an unprepped night — that's what it's *for*.

---

## Part 2 — The 10-Minute Wrap-Up *(same night, before sleep — this is the step that keeps 119 files true)*

- [ ] **Turn 1–2 front dials** — [[world-in-motion]] Front Tracker: one line each in "Current stage." Advance the fronts they *brushed but didn't resolve*. Never all of them.
- [ ] **Tick the ledgers** — [[the-celebration-clue-map]] hint statuses + each spotlighted PC's arc-file ledger: what fired, which channel.
- [ ] **Three lines in [[STATUS]]** → Where We Are: what changed, what's now top thread, what the party said they want next.
- [ ] **Bank unfired secrets** — mark them in the run sheet or paste into a next-session stub.
- [ ] **Improvised canon** — any name, place, or fact you made up at the table: write it down NOW with one line of context. (Grep-for-collisions and file-sweeps can wait for the co-author; the *capture* can't.)
- [ ] **One lesson?** If the night taught you something about running this table, add a line to CLAUDE.md → Table-Tested Lessons.
- [ ] **What lit them up** — one name + one moment. That's next week's step-one answer, waiting for you.

Then sleep. The deep work (new set pieces, canon sweeps, reconciles) belongs to a co-author session, not to tonight.

---

*Why this shape: fixed order kills decision fatigue; timeboxes kill perfectionism; the wrap-up is small enough to survive being tired. If a step consistently gets skipped, don't push harder — shrink the step and note it in Table-Tested Lessons.*
